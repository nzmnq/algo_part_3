**Тема:** Реалізація користувацьких функцій та ітераційних процесів мовою Rust (портинг Лабораторної роботи №4)

## 🎯 Мета роботи

- Опанувати принципи розроблення прикладних обчислювальних програм сучасною системною мовою програмування **Rust**.
- Засвоїти фундаментальні концепції безпеки та типізації мови Rust: строгу статичну типізацію, обов'язкове явне зведення типів (`as f64`), концепцію незмінності за замовчуванням та контрольовану змінюваність (`let mut`).
- Вивчити роботу з математичними константами і функціями стандартної бібліотеки (`std::f64::consts::PI`, `sin()`, `abs()`), а також з консольним введенням-виведенням через модуль `std::io`.
- Здійснити повторну реалізацію (портинг) алгоритму обчислення розкладу аналітичної функції у тригонометричний ряд Фур'є з мови C++ (Лабораторна робота №4) на мову Rust.
- Обчислити значення функції на заданому інтервалі для двох випадків:
  1. фіксованого числа доданків $n = 10$ (сума $S_n$);
  2. заданої точності $eps = 0.0001$ (сума $S_e$).
- Дослідити швидкість збіжності, числову стабільність і провести порівняльний аналіз результатів із точним аналітичним значенням функції $y(x)$.

## 📋 Варіант завдання (Варіант 8)

- **Цільова аналітична функція:**
  $$y(x) = \frac{1}{4} \pi x$$
- **Інтервал зміни аргументу:** $0 \le x \le \pi/2$ ($a = 0.0$, $b = \pi/2 \approx 1.5707963$)
- **Кількість розрахункових точок:** $k = 10$
- **Крок зміни аргументу:**
  $$\text{step} = \frac{b - a}{k - 1} = \frac{\pi/2 - 0}{9} = \frac{\pi}{18} \approx 0.1745329 \text{ рад } (10^\circ)$$
- **Кількість членів ряду для першого розрахунку:** $n = 10$ (11 доданків від $k = 0$ до $k = 10$)
- **Задана точність для другого розрахунку:** $eps = 0.0001 = 10^{-4}$
- **Розклад функції у тригонометричний ряд Фур'є:**
  $$S(x) = \sin(x) - \frac{\sin(3x)}{3^2} + \frac{\sin(5x)}{5^2} - \frac{\sin(7x)}{7^2} + \dots + (-1)^n \frac{\sin((2n+1)x)}{(2n+1)^2}, \quad n \ge 0$$
- **Формула $k$-го члена ряду:**
  $$a_k(x) = (-1)^k \frac{\sin((2k+1)x)}{(2k+1)^2}, \quad k = 0, 1, 2, \dots$$

## 💻 Архітектура та сирцевий код програми ([src/main.rs](src/main.rs))

```rust
use std::f64::consts::PI;
use std::io::{self, Write};

/// еталонна функція
fn y(x: f64) -> f64 {
    (PI * x) / 4.0
}

/// обчислення k-го члена ряду
fn term(x: f64, k: i32) -> f64 {
    let m = (2 * k + 1) as f64;
    let denom = m * m;
    let mut ak = (m * x).sin() / denom;
    if k % 2 != 0 {
        ak = -ak;
    }
    ak
}

fn sum1(x: f64, n: i32) -> f64 {
    let mut z: f64 = 0.0;
    for k in 0..=n {
        z += term(x, k);
    }
    z
}

/// ітераційне обчислення суми ряду із заданою точністю eps (|ak| > eps)
fn sum2(x: f64, eps: f64) -> f64 {
    let mut z: f64 = 0.0;
    let mut ak: f64 = 1.0;
    let mut k: i32 = 0;
    while ak.abs() > eps {
        ak = term(x, k);
        z += ak;
        k += 1;
    }
    z
}

fn main() {
    let delta: f64 = 0.0001;
    let x1: f64 = 0.0;
    let x2: f64 = PI / 2.0;
    let step: f64 = (x2 - x1) / (10.0 - 1.0);
    let n = 10;
    println!();
    println!("{:>10}{:>12}{:>12}{:>12}", "x", "Sn", "Se", "y");
    println!("----------------------------------------------");

    for j in 1..=10 {
        let x = x1 + (j - 1) as f64 * step;

        let sn = sum1(x, n);
        let se = sum2(x, delta);
        let y_val = y(x);

        println!(
            "{:>10.5}{:>12.5}{:>12.5}{:>12.5}",
            x, sn, se, y_val
        );
    }
}
```

## 📋 Варіант завдання (Варіант 8)

> **Умова:** Скласти програму, що підраховує число слів у рядку, уведеного користувачем. Для цього написати функцію із прототипом:
> ```cpp
> int num_word (char *s);
> ```

### Параметри завдання:
- **Буфер рядка:** статичний масив `char str[MAX_LEN]` розміром 256 символів (`#define MAX_LEN 256`).
- **Введення рядка:** `cin.getline(str, MAX_LEN)` для зчитування рядка разом із пробілами між словами.
- **Розділювачі:** пробільні символи (пробіл, знак табуляції, перехід рядка), що ідентифікуються через `isspace((unsigned char)*s)`.
- **Стійкість до крайових випадків:** коректне опрацювання множинних послідовних пробілів між словами, початкових (провідних) пробілів, завершальних пробілів та порожнього рядка.

## 💻 Модульна структура програми ([src/main.cpp](file:///Users/nazardoskochynskyy/algo_part_3/src/main.cpp))

```cpp
#include <iostream>
#include <cctype>
#include <cstring>

using namespace std;

#define MAX_LEN 256

int num_word(char *s);

int main() {
    char str[MAX_LEN];

    cout << "Введіть рядок тексту: ";
    cin.getline(str, MAX_LEN);

    int count = num_word(str);

    cout << "\nВведений рядок: \"" << str << "\"" << endl;
    cout << "Кількість слів у рядку: " << count << endl;

    return 0;
}

int num_word(char *s) {
    int count = 0;
    bool inWord = false;

    while (*s != '\0') {
        if (!isspace((unsigned char)*s)) {
            if (!inWord) {
                inWord = true;
                count++;
            }
        } else {
            inWord = false;
        }
        s++;
    }

    return count;
}
```
